# LifeFlow Requirements Traceability

## Purpose and evidence policy

This document maps the official BIT1123 Object Oriented Programming final
project brief to the current LifeFlow implementation. The source brief is
`BIT1123 Object Oriented Programming (Java)_final-project-group_40%_202605.docx`,
provided separately from the repository.

The review uses only five statuses:

- `MET`: the repository contains direct implementation evidence and, where
  applicable, automated test evidence.
- `PARTIALLY MET`: useful evidence exists, but part of the wording or required
  submission artifact is not yet complete.
- `NOT MET`: the current repository does not implement the requirement.
- `PENDING DELIVERABLE`: the requirement depends on a future presentation,
  demonstration, scheduling, or LMS submission action.
- `HUMAN EVIDENCE REQUIRED`: the requirement cannot be established from source
  code and must be supplied by the team.

The rubric weights printed in the brief total **105 marks**
(`15 + 15 + 20 + 20 + 10 + 10 + 5 + 5 + 5`), although the project is described
as a 40% assessment. This document preserves the published figures and does not
normalise them.
