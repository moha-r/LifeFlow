# Runtime data

LifeFlow creates the following files here when data is saved:

- `donors.txt`
- `blood_units.txt`
- `requests.txt`

The files are excluded from Git because they may contain demonstration data.
Use fictional names during presentations and testing.

The `demo/` folder contains a fictional ready-made scenario. To use it, copy
its three text files into this `data/` folder before starting the application.
The emergency request will be selected before the regular request.
